# Instructor README — SEIS 201 Unit 1 HW Case B

This is the **transfer homework case** that follows the M02 class case. The class
case remains Otter Bend; this homework case is Oak Street Lift Station. Do not
assign this package before the M02 reveal.

## Scenario

ACMEJOB.Ai is supporting fictional client Westfield Public Works during startup
of the fictional Oak Street Lift Station. Diane Halvorsen, PE; Wes Tanaka, EIT;
and FOREMAN v4.2 return in a new setting. Eight discharge-pressure transducers
are checked under one defined no-flow standby condition.

The student package practices:

- measurement uncertainty and channel-to-channel comparison;
- random versus systematic error;
- precision versus accuracy;
- refusing a false average that hides a bad channel; and
- documenting a defensible decision log.

## Data provenance

The dataset is generated by
`tools/teaching-pack/generate_hw_case_b.py` with Python's deterministic
`random.Random` seed **2010107**. Re-running that script regenerates the CSV and
all quoted statistics.

Build the branded Word handout from the Markdown source with
`python3 tools/teaching-pack/make_hw_case_b.py`. That builder uses the shared
`doclib.py` course-handout pattern and brand tokens.

All sites, organizations, specifications, and values are fictional,
schematic/instructional, and not verified by a licensed engineer. No artifact
is suitable for design, construction, operation, or public-safety decisions.
